🧮 Mathematical Foundation of Face Detection

Q1: How is an image represented mathematically?

Answer: Digital images are represented as multi-dimensional matrices. For grayscale images, we have a 2D matrix where each element represents pixel intensity (0-255). For RGB color images, we stack three such matrices.

$$I_{gray}(x,y) = \begin{bmatrix} p_{1,1} & p_{1,2} & \cdots & p_{1,n} \\ p_{2,1} & p_{2,2} & \cdots & p_{2,n} \\ \vdots & \vdots & \ddots & \vdots \\ p_{m,1} & p_{m,2} & \cdots & p_{m,n} \end{bmatrix}$$ $$I_{RGB} = [I_R, I_G, I_B] \text{ where each channel is a 2D matrix}$$

Q2: What is Convolution and why is it crucial for feature detection?

Answer: Convolution is a mathematical operation that slides a filter (kernel) across the image to detect specific features like edges, corners, or textures. This is the core operation in Convolutional Neural Networks (CNNs).

$$(I * K)(x,y) = \sum_{m=-a}^{a} \sum_{n=-b}^{b} I(x+m, y+n) \cdot K(m,n)$$

Where $K$ is the convolution kernel and $I$ is the input image.

$$\text{Edge Detection Kernel: } K_{edge} = \begin{bmatrix} -1 & -1 & -1 \\ -1 & 8 & -1 \\ -1 & -1 & -1 \end{bmatrix}$$

Q3: How does the neural network make predictions?

Answer: The network uses the sigmoid activation function to convert raw scores into probabilities. Multiple layers transform the input through weighted combinations and non-linear activations.

$$\sigma(z) = \frac{1}{1 + e^{-z}} \text{ where } z = \sum_{i=1}^{n} w_i x_i + b$$ $$P(\text{face}|x) = \sigma(W \cdot \phi(x) + b)$$

Where $\phi(x)$ represents the learned feature representation of input $x$.

Q4: How are bounding boxes calculated?

Answer: Face detection models predict bounding box coordinates and dimensions. The output includes center coordinates, width, height, and confidence score.

$$\text{Bounding Box: } B = (x_{center}, y_{center}, width, height, confidence)$$ $$\text{Corner Coordinates: } \begin{cases} x_{min} = x_{center} - \frac{width}{2} \\ y_{min} = y_{center} - \frac{height}{2} \\ x_{max} = x_{center} + \frac{width}{2} \\ y_{max} = y_{center} + \frac{height}{2} \end{cases}$$

Q5: What is Non-Maximum Suppression (NMS)?

Answer: NMS eliminates duplicate detections by calculating Intersection over Union (IoU) between overlapping boxes and keeping only the highest confidence detection.

$$IoU = \frac{\text{Area of Intersection}}{\text{Area of Union}} = \frac{|B_1 \cap B_2|}{|B_1 \cup B_2|}$$ $$\text{Keep box if: } IoU < \text{threshold} \text{ or } \text{confidence}> \text{max confidence}$$

Q6: How is detection confidence calculated?

Answer: Confidence combines objectness score (probability that box contains an object) with classification probability.

$$\text{Confidence} = P(\text{Object}) \times P(\text{Class}|\text{Object}) \times IoU_{pred}^{truth}$$ $$\text{Final Score} = \sigma(\text{raw output}) \times 100\%$$

Q7: How does real-time processing work?

Answer: Frame rate (FPS) is calculated by measuring processing time per frame. Optimization techniques like model quantization and efficient architectures enable real-time performance.

$$FPS = \frac{1}{\text{Processing Time per Frame}}$$ $$\text{Processing Time} = T_{preprocessing} + T_{inference} + T_{postprocessing}$$
